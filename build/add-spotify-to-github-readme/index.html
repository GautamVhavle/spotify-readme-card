Spotify README Card

Guide

Add Spotify to your GitHub README.

A Spotify README card is an SVG image that shows the song you are playing on your GitHub profile. You deploy it once, then paste the image URL into your README.

Five steps, then one line of Markdown.

  1. 1
    Create a Spotify app

    Open the Spotify Developer Dashboard and create an app. Add this redirect URI exactly. Spotify rejects localhost, so it has to be the loopback IP. Enable the Web API, then copy the client ID and client secret. 

    http://127.0.0.1:5175/callback
  2. 2
    Add the credentials locally

    Clone the repository, install dependencies, and copy the example env file. Put the client ID and client secret in .env.

    git clone https://github.com/GautamVhavle/spotify-readme-card.git
cd spotify-readme-card
npm install
cp .env.example .env
  3. 3
    Generate a refresh token

    Run the authorise script, open the printed URL, and approve access. The script writes SPOTIFY_REFRESH_TOKEN into .env.

    npm run authorize
  4. 4
    Deploy to Vercel

    Deploy the project and set three environment variables: SPOTIFY_CLIENT_ID, SPOTIFY_CLIENT_SECRET, and SPOTIFY_REFRESH_TOKEN. The free Vercel plan is enough. You can also use the Deploy button on the homepage.

  5. 5
    Paste the image into your README

    GitHub renders the URL as your now-playing card. /small is the compact card. /portrait is the portrait card, coloured by the album art.

    <img src="https://YOUR-APP.vercel.app/" alt="What I'm listening to" width="420" />

Straight answers.

What is a Spotify README card?
A Spotify README card is an SVG image that shows the song you are playing on your GitHub profile. You deploy it once, then paste the image URL into your README.
How do I add a Spotify now playing card to my GitHub README?
Create a Spotify app, authorise it once to get a refresh token, deploy the project to Vercel with your client ID, client secret and refresh token as environment variables, then paste the returned image URL into your README as a Markdown image.
Is Spotify Readme Card free?
Yes. It is MIT licensed, self-hosted on a free Vercel account, and has zero runtime dependencies.
Which layouts and themes are available?
Three layouts: detailed, compact, and portrait. Eleven built-in themes, plus hex colour overrides for background, text, accent, and border. The portrait card takes its colour from the album art.
